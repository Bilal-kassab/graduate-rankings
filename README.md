# مراتب — ترتيب طلاب التخرج

موقع عربي ثابت (RTL) يعمل مباشرة على **GitHub Pages** بدون إطار عمل أو بناء أو اشتراكات. يعرض **301** طالباً وطالبة وفق معدلاتهم من الأعلى إلى الأدنى من مسودة قرار تخرج قسم هندسة البرمجيات ونظم المعلومات للعام الدراسي **2025–2026**.

## ⚠️ قبل نشره للعامة

**يتضمن `data/students.json` أسماء الطلاب وأرقامهم الوطنية الكاملة ومعدلاتهم.** عند رفعه إلى مستودع عام على GitHub ونشره عبر Pages، سيكون الملف نفسه قابلاً للتنزيل لأي زائر، حتى لو أخفيت العمود من الواجهة. **تأكد من أن لديك موافقة أو أساساً قانونياً لنشر هذه البيانات الشخصية.** إن لم تتوفر هذه الصلاحية، لا تنشر الموقع بنسخته الحالية؛ استخدم نسخة منقّحة تحذف الأرقام الوطنية/تستبدلها برموز غير حساسة.

## كيفية النشر على GitHub Pages

1. فك الضغط عن ملف المشروع.
2. ادخل إلى GitHub وأنشئ مستودعاً جديداً، مثلاً `graduate-rankings`.
3. ارفع **محتويات** مجلد المشروع إلى جذر المستودع، بما فيها `index.html` و`assets/` و`data/` و`.nojekyll` (لا ترفع المجلد الخارجي فقط إن أردت أن تكون `index.html` في الجذر).
4. افتح **Settings → Pages → Build and deployment**.
5. ضمن **Source** اختر **Deploy from a branch**، ثم **main** والمجلد **/(root)** واضغط **Save**.
6. بعد اكتمال النشر سيظهر الموقع عادةً على الرابط:
   `https://USERNAME.github.io/graduate-rankings/`

> عند استخدام حساب أو اسم مستودع آخر، استبدل `USERNAME` و`graduate-rankings` بالقيم الصحيحة.

## المعاينة محلياً

من داخل مجلد المشروع، شغّل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/` بالمتصفح. **فتح `index.html` بالنقر المزدوج قد يمنع قراءة JSON** بسبب قيود أمان المتصفح؛ GitHub Pages يعمل بشكل طبيعي.

## المزايا

- بحث فوري بالاسم الكامل أو بجزء منه (ويمكن إدخال أجزاء الاسم بأي ترتيب)، وبالرقم الوطني كاملاً أو جزئياً.
- البحث يعمل مع الأرقام العربية `٠١٢٣` والإنجليزية `0123`، ومع فروق كتابة الهمزات والتاء المربوطة.
- تصفية حسب التقدير (امتياز، جيد جداً، جيد).
- الترتيب بالأعلى معدل، بالأقل معدل، أبجدياً، أو حسب التسلسل الأصلي للمسودة.
- لوحة صدارة الثلاثة الأوائل، وبطاقات إحصائية، وصفحات نتائج، وتفاصيل للطلاب، ونسخ الرقم الوطني، وتصدير CSV للنتائج المصفّاة.
- تصميم متجاوب مع الهاتف والحاسوب ولوحات المفاتيح؛ الاختصار `Ctrl+K` أو `⌘+K` يركز البحث.
- يعمل بدون أي خادم خلفي أو API؛ جميع البيانات محلية ضمن المشروع.

## ملاحظات الدقة

- تم استخراج 301 سجل من **14 صفحة** والتحقق من اكتمال التسلسل الأصلي `1–301`، وعدم تكرار أي رقم وطني ظاهر، وترتيب المعدلات تنازلياً.
- **السجل رقم 75 من المصدر** (حلا أنور اليونس، ترتيبه 289 بالمعدل 69.02) **لا يتضمن رقماً وطنياً** في المسودة، ولذلك وضعنا `null` بدلاً من اختراع رقم.
- عند تساوي المعدل، يُقدّم صاحب التسلسل الأصغر في الكشف الأصلي. لا تتغير **الرتبة الأصلية المحسوبة** عند البحث أو إعادة فرز العرض.
- التصنيف المعروض: امتياز للمعدل **85 فأكثر**، جيد جداً للمعدل **75 إلى أقل من 85**، وجيد لما هو **أقل من 75**.
- الأسماء من نصوص المسودة المرفقة مع مراجعة تصحيحات نصية لأخطاء استخراج PDF. يُنصح بالمراجعة البشرية النهائية قبل اعتماد البيانات في وثيقة رسمية؛ هذه واجهة بحث في *مسودة* وليست وثيقة معتمدة.

## الملفات

```text
.
├── index.html             الصفحة الرئيسية
├── assets/
│   ├── styles.css         التصميم والاستجابة للشاشات
│   ├── app.js             البحث والتصفية والترتيب والتفاعل
│   └── favicon.svg        أيقونة الموقع
├── data/
│   └── students.json      بيانات الطلاب وعددهم 301
├── .nojekyll              منع معالجة الموقع عبر Jekyll
└── README.md              تعليمات الاستخدام والنشر
```

## تغيير بيانات الطلاب

حرّر `data/students.json` مع المحافظة على الحقول الحالية (`rank`, `name`, `nationalId`, `average`, `grade`, `originalIndex`, `sourcePage`). التطبيق يتحقق من كون البيانات **301** سجلاً كي لا تظهر قائمة ناقصة دون تنبيه. إذا تغير عدد الطلاب في نسخة أحدث، غيّر شرط التحقق هذا في `assets/app.js` أيضاً.
